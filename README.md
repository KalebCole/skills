# kalebcole/skills

Kaleb's personal skills registry for AI agent runtimes (Hermes, GitHub Copilot CLI). Skills follow the [Agent Skills Convention](https://github.com/anthropics/skills) — a `SKILL.md` per skill, with YAML frontmatter declaring `name` and `description`.

One source of truth, two install targets. The `install.sh` script symlinks every active skill into both `~/.hermes/skills/` and `~/.copilot/skills/`, so editing once propagates everywhere.

## Layout

```
skills/
├── engineering/      — code, tooling, dev workflows
├── productivity/     — generic productivity patterns
├── personal/         — tied to my accounts (YNAB, Todoist, etc.)
├── in-progress/      — half-built; excluded from install
└── deprecated/       — kept for reference; excluded from install
```

## Install

```bash
git clone https://github.com/kalebcole/skills.git ~/kalebcole-skills
cd ~/kalebcole-skills
./scripts/install.sh
```

First-run collisions fail loudly. Re-run with `--force` to back up existing entries (`<name>.bak`) and replace them with symlinks.
