# skills

My skills for [Hermes](https://hermes-agent.nousresearch.com/) and GitHub Copilot CLI.

Both runtimes read the same `SKILL.md` format, so I keep one copy here and symlink into `~/.hermes/skills/` and `~/.copilot/skills/`. Editing once updates both.

This is a personal registry — most skills assume my accounts and machine. Fork freely, but expect to rewrite the `personal/` ones.

## Install

```bash
git clone https://github.com/kalebcole/skills.git ~/kalebcole-skills
~/kalebcole-skills/scripts/install.sh
```

`--force` overwrites existing skills (backed up as `<name>.bak`).
